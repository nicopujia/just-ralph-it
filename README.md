# JRI (i.e. [Just Ralph It](https://justralph.it), a.k.a. [Ralfealo](https://ralfealo.com))

## Getting started

### Prerrequisites

- [uv](https://docs.astral.sh/uv/)

### Setup

```bash
# Install dependencies
uv sync

# Install JRI globally
uv tool install -e .

# Run it
jri --help
```
