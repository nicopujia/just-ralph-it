# Overview

Welcome to Just Ralph It, the AI-powered code automation platform.

## What is Just Ralph It?

Just Ralph It is a platform that helps you build software projects using AI agents. Our system uses two specialized agents:

- **Ralphy**: Interviews you to understand your project requirements
- **Ralph**: Implements your project using test-driven development

## How It Works

1. **Describe your project** - Tell Ralphy what you want to build
2. **Get a plan** - Ralphy creates detailed issues for your project
3. **Watch it build** - Ralph picks up issues and implements them one by one
4. **Deploy** - Your project is automatically deployed when ready

## Getting Started

To get started, simply log in with your GitHub account and create a new project.
