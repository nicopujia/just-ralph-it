# Roadmap

## Phases

1. **Core Engine**: idea -> tasks -> loop -> convergence
2. **Loop Hardening**: reliability, observability, failure semantics
3. **Remote Execution**: abstract execution, VPS
4. **Autonomy**: continuous self-triggering execution
5. **Reconciliation**: scan codebase, detect bugs, generate tasks
6. **Multi-Project**: manage multiple repos
7. **Web UI**: visualization layer over CLI
8. **Productization**: auth, billing, hosted platform

Currently finishing phase 2.
