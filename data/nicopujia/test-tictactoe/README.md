# test-tictactoe

A simple tic tac toe game

## Project Overview

- **Type**: Web game (single HTML file)
- **Players**: Two players on the same device (pass and play)
- **Core functionality**: Classic tic tac toe with win/draw detection

## Features

- 3x3 clickable grid
- Alternating X and O marks
- Win detection (rows, columns, diagonals)
- Draw detection
- Turn indicator
- New Game button to reset
