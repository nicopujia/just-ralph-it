A simple two-player tic tac toe game for the web.

**Core Features:**
- 3x3 clickable grid
- Alternating X and O marks
- Win detection (rows, columns, diagonals)
- Draw detection
- Turn indicator
- New Game button to reset

**Tech Stack:** Plain HTML, CSS, JavaScript (single HTML file)
