# Contributing to Just Ralph It

Given the project's very early stages, neither code contributions nor feature requests are sought at the moment. 

Nevertheless, feel free to report bugs as [GitHub issues](https://github.com/nicopujia/just-ralph-it/issues) whenever you encounter one, or to share your feedback via [email](mailto:nicolas@justralph.it).

Thanks for your interest, and please star the repo if you found it useful!
